# Sistem Helpdesk / Aduan Organisasi

Repositori ini mengandungi kod sumber untuk Sistem Helpdesk / Aduan, sebuah sistem yang dibina menggunakan kerangka kerja (framework) **Laravel**. Sistem ini bertujuan untuk memudahkan pengurusan dan penjejakan aduan serta permintaan bantuan di dalam organisasi.

## Teknologi Utama
- **Backend & Framework:** Laravel (PHP)
- **Database:** (Akan ditentukan - cth: MySQL / PostgreSQL)
- **Frontend:** (Akan ditentukan - cth: Blade Templates / Tailwind CSS)

## Tujuan Projek
Sistem ini membolehkan kakitangan menghantar tiket aduan, dan membolehkan pihak admin/pasukan sokongan untuk mengurus, membalas, dan menjejak status aduan tersebut sehingga selesai.
